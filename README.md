# Курсовая работа по теории автоматического управления

## Краткое описание

Разработана математическая модель электромеханической системы с упругим редуктором (двухмассовая модель). Синтезирован **ПИД-регулятор** с отрицательной обратной связью по углу, угловой скорости и интегралу от ошибки.

На основе характеристического уравнения шестого порядка и критерия Рауса‑Гурвица определена область устойчивости в пространстве параметров \((k_p, k_d, k_i)\). С учётом ограничений:
- максимальный крутящий момент на выходном валу \(|M_m|_{\max} < 150\) Нм,
- максимальное управляющее напряжение \(|u|_{\max} < 220\) В,

построены области допустимых параметров и линии равных длительностей переходных процессов. Введён интегральный квадратичный функционал качества \(J(\rho) = \int_0^{t_p} (\psi_m^2 + \rho u^2) dt\) и найдены оптимальные параметры регулятора, обеспечивающие наилучшее быстродействие при выполнении всех ограничений.

## Основные результаты

- **Оптимальные параметры ПИД-регулятора:**  
  \(k_p = 500\), \(k_d = 10\), \(k_i = 1\).

- **Длительность переходного процесса:**  
  \(t_p \approx 0.4\) с (время вхождения ошибки в 10%‑ю зону от \(\varphi^* = 180^\circ\)).

- **Перерегулирование:** \(\sigma \approx 10\%\).

- **Максимальный крутящий момент:** \(|M_m|_{\max} \approx 140\) Нм (запас 10 Нм).

- **Максимальное напряжение управления:** \(|u|_{\max} \approx 180\) В (запас 40 В).

- **Установившаяся ошибка:** нулевая (астатизм второго порядка).

Все требования технического задания выполнены.
