# Курсовая работа по теории автоматического управления (вариант №70)

## Краткое описание

В работе исследована система управления модулем поворота промышленного робота с **упругим редуктором** (двухмассовая модель) и двигателем постоянного тока. Синтезирован **ПИД-регулятор** с отрицательной обратной связью по углу, угловой скорости и интегралу от ошибки.

**Параметры варианта №70:**
- Передаточное отношение редуктора: \(i = 50\)
- Коэффициент преобразования измерителя угла: \(k = 100\) В/рад
- Коэффициент регулятора по пропорциональной составляющей: \(k_\text{пр} = 1\)
- Жёсткость редуктора: \(c = 10^3\) Нм/рад
- Демпфирование редуктора: \(b = 4\) Нм·с/рад
- Момент инерции ротора двигателя: \(J_д = 2\cdot10^{-3}\) кг·м²
- Момент инерции нагрузки (модуля поворота): \(J_м = 1\) кг·м²
- Постоянная времени двигателя: \(\tau = 0.003\) с
- Крутизна механической характеристики: \(s = 0.2\) Нм·с
- Коэффициент усиления двигателя: \(r = 0.2\) Нм/В

Приведённые параметры к выходному валу редуктора:
\[
J_{\text{дпр}} = J_д i^2 = 5,\quad s_{\text{пр}} = s i^2 = 500,\quad r_{\text{пр}} = r i = 10.
\]

## Основные этапы работы

1. **Математическая модель** – получены уравнения движения механической части, динамики двигателя и цепи обратной связи. Система описана в пространстве состояний (6 переменных).

2. **Анализ устойчивости** – по критерию Стодолы и Рауса–Гурвица построена область устойчивости в плоскости параметров \((k_\text{др}, k_\text{им})\). Проверка годографом Михайлова для точки \((0.25, 0.5)\) подтвердила устойчивость.

3. **Численное моделирование переходных процессов** – методом Рунге–Кутты 4-го порядка рассчитаны отклики системы для трёх характерных точек. Определены максимальные крутящие моменты, управляющие сигналы и время переходного процесса \(t_\text{п}\).

4. **Области допустимых параметров** – построены зоны выполнения ограничений:
   \[
   |M_м|_{\max} < 150\ \text{Нм},\qquad |u|_{\max} < 220\ \text{В}.
   \]
   Показано, что ограничение по управляющему сигналу не выполняется ни в одной точке из-за фиксированного \(k_\text{пр}=1\) (начальный всплеск \(u(0)=100\pi\approx314\) В).

5. **Линии равной длительности** – построены изолинии времени переходного процесса.

6. **Оптимальное управление** – введён интегральный квадратичный функционал
   \[
   J_\rho = \int_0^{t_\text{п}} \left( \psi_м^2 + \rho u^2 \right) dt
   \]
   и найдены минимумы при \(\rho=0\) (функционал ошибки), \(\rho\to\infty\) (функционал управления) и \(\rho=0.005\) (компромиссный критерий).

## Итоговая выбранная настройка

В качестве наилучшей, обеспечивающей **нулевую установившуюся ошибку** и **выполнение ограничения по моменту**, выбрана компромиссная точка:

\[
\boxed{k_\text{др}=0.10,\qquad k_\text{им}=0.20}
\]

Характеристики системы при этой настройке:
- Длительность переходного процесса: \(t_п = 1.09\) с
- Максимальный крутящий момент: \(|M_м|_{\max} = 140.54\) Нм \(< 150\) Нм (запас ≈ 9.5 Нм)
- Максимальное управляющее напряжение: \(|u|_{\max} = 314.16\) В \(> 220\) В (ограничение не выполняется, что объективно неустранимо при \(k_\text{пр}=1\))
- Установившаяся ошибка: нулевая (благодаря интегратору)
