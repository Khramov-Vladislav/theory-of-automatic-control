# Курсовая работа по теории автоматического управления

## Краткое описание

В работе исследована система управления модулем поворота промышленного робота (вариант 70). Разработана математическая модель электромеханической системы, учитывающая упругость редуктора (двухмассовая модель), динамику двигателя постоянного тока и измерительные цепи. Синтезирован **ПИД-регулятор** с отрицательной обратной связью по углу, угловой скорости и интегралу от ошибки.

Параметры варианта 70:  
- передаточное отношение редуктора \(\text{Кдр}=i=50\);  
- коэффициент преобразования измерителя \(\text{Ким}=k=100\);  
- дополнительный коэффициент регулятора \(\text{Кпр}=1\);  
- жёсткость редуктора \(c=10^3\) Нм, демпфирование \(b=4\) Нм·с;  
- момент инерции ротора \(J_д=2\cdot10^{-3}\) кг·м², нагрузки \(J_M=1\) кг·м²;  
- постоянная времени двигателя \(\tau=0.003\) с, крутизна механической характеристики \(s=0.02\) Нм·с, коэффициент усиления \(r=0.2\) Нм/В.

На основе характеристического уравнения **шестого порядка** (благодаря интегратору) и критерия Рауса‑Гурвица построена область устойчивости в пространстве параметров \(\{\text{Кдр}, \text{Ким}\}\) (т.е. \(i\) и \(k\)) при фиксированных оптимальных коэффициентах ПИД-регулятора. С учётом ограничений:
- максимальный крутящий момент на выходном валу \(|M_m|_{\max} < 150\) Нм,
- максимальное управляющее напряжение \(|u|_{\max} < 220\) В,

определены области допустимых параметров, построены линии равных длительностей переходных процессов. Введён интегральный квадратичный функционал качества \(J(\rho) = \int_0^{t_p} (\psi_m^2 + \rho u^2) dt\) и найдены оптимальные параметры регулятора, обеспечивающие наилучшее быстродействие при соблюдении всех ограничений.

## Основные результаты

- **Оптимальные параметры ПИД-регулятора (для заданных Кдр=50, Ким=100, Кпр=1):**  
  \(k_p = 80,\quad k_d = 6,\quad k_i = 1\).

- **Длительность переходного процесса:**  
  \(t_p \approx 0.5\) с (время вхождения ошибки в 10%‑ю зону от \(\varphi^* = 180^\circ\)).

- **Перерегулирование:** \(\sigma \approx 12\%\).

- **Максимальный крутящий момент:** \(|M_m|_{\max} \approx 140\) Нм (запас 10 Нм).

- **Максимальное напряжение управления:** \(|u|_{\max} \approx 180\) В (запас 40 В).

- **Установившаяся ошибка:** нулевая (астатизм второго порядка за счёт интегратора).

Все требования технического задания выполнены. Полученные результаты могут быть использованы при настройке реальной системы управления промышленного робота.
